CYD Dashboard — Flasher

Flash the latest firmware straight to your Cheap Yellow Display from the browser. No Arduino IDE or PlatformIO needed.

Your browser does not support Web Serial. Use Chrome or Edge on a computer (not mobile).
How to
  1. Open this page in Chrome or Edge on a computer.
  2. Plug the CYD into USB.
  3. Click Flash CYD and pick the serial port (CH340/CP2102).
  4. After flashing, the page asks for your WiFi (via Improv) — enter SSID and password.
  5. Once WiFi is up, the device's config page opens automatically — set the MQTT broker, topic and more there.
  6. The gauge runs. The device IP is shown at the bottom of the screen, so you can always reopen the config page.

No credentials are built into the firmware — WiFi is set via Improv in the browser, MQTT via the device's own config page. Everything is stored on the device and survives a restart.
