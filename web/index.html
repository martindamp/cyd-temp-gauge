CYD Temp Gauge — Flasher

Flash den seneste firmware direkte til din Cheap Yellow Display fra browseren. Ingen Arduino IDE eller PlatformIO nødvendig.

Din browser understøtter ikke Web Serial. Brug Chrome eller Edge på en computer (ikke mobil).
Sådan gør du
  1. Åbn siden i Chrome eller Edge på en computer.
  2. Sæt CYD'en i USB.
  3. Klik Flash CYD og vælg den serielle port (CH340/CP2102).
  4. Efter flash beder siden om dit WiFi (via Improv) — tast SSID og password.
  5. Når WiFi er oppe, åbner enhedens konfig-side automatisk — her sætter du MQTT-broker, topic m.m.
  6. Gaugen kører. Enhedens IP vises nederst på skærmen, så du altid kan åbne konfig-siden igen.

Ingen credentials bygges ind i firmwaren — WiFi sættes via Improv i browseren, MQTT via enhedens egen konfig-side. Det hele gemmes på enheden og overlever genstart.
